# 又又的森林大冒险 · 阳光森林 🌲

绘本风格的横版森林冒险小游戏，V1.0 体验版。每天从温暖的家出发，收集木头、制作装备，遇见调皮的蘑菇怪，再带着收获回家。

当前是一张固定的阳光森林地图，不是随机地图或完整的每日冒险系统。欢迎 Fork，学习和修改自己的版本。

## 启动游戏

游戏使用原生 HTML、CSS、JavaScript 和 Canvas，没有构建步骤，不需要 API Key 或后端服务。图片和动画素材均随仓库提供。

先安装 Python 3，然后执行：

```sh
git clone https://github.com/july-lyan/yoyo-sunshine-forest.git
cd yoyo-sunshine-forest
python3 -m http.server 4173 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:4173 。请通过本地服务打开，不要直接双击 index.html（模块和动画配置需要通过 HTTP 加载）。

如已安装 Node.js/npm 和 Python 3，也可以使用 `npm start`。

## 怎么玩

- A / D 或左右方向键：移动。
- 空格 / W / ↑：跳跃。
- 鼠标左键点击或按住画面：朝点击方向攻击或采集；也可以按住 J。
- 1 选择剑，2 选择斧头：剑打怪更快，斧头采木更快。
- E：工作台、回家等互动；触屏提供移动、跳跃、攻击和互动按钮。
- 工作台可制作石剑、石斧、木护甲、石护甲。
- 跳台上有石头和爱心；蘑菇王会预警、起跳并释放双向地波，可以跳跃躲避。
- 拿到蘑菇徽章，并保留至少 12 块木头，回到家完成冒险。
- 进度保存在当前浏览器的 localStorage 中；清理浏览器数据会丢失进度。

## 从哪里开始修改

| 文件 | 内容 |
| --- | --- |
| `balance.js` | 武器伤害、采集效率、怪物数值和制作配方 |
| `engine.js` | 移动、跳跃、碰撞、怪物行为、任务和存档 |
| `app.js` | 画面绘制、镜头、动画、键鼠触屏输入、音效与界面 |
| `index.html` / `style.css` | 页面结构、工具栏、弹窗和响应式布局 |
| `assets/` | 生成式场景、角色和道具素材 |
| `assets/animations.json` | 动画帧切片与脚底锚点 |
| `engine.test.mjs` | 游戏逻辑回归测试 |

测试需要支持 `node --test` 的 Node.js（建议 20 或更高版本）：

```sh
npm test
```

不需要先运行 npm install。

## 当前边界

- 当前提供源码，不包含已部署的在线试玩服务。
- 桌面浏览器是主要体验环境；已有触屏操作，但手机横屏仍有页面高度溢出问题，尚未完成真实 iOS / Android 设备验收。
- 当前版本不能直接作为小红书小工具上传：动画配置使用 fetch，全屏依赖浏览器能力，需要适配平台容器。
- 弓箭、多主题地图、随机冒险、家园防守尚未实现。
- 动画采用有限帧素材，不是完整骨骼动画。
