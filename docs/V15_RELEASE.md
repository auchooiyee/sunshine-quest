# v0.15 — Canyon Landing

8 November 2026 (Malaysia).

Choose **Next: Land at the canyon** after lighting the camp lanterns, or open **Canyon Landing** under Field missions. The map shows the number of badges earned across all five field missions. It does not require them to be completed in order.

Choose a whole-number landing point by tapping the coordinate grid or using the x and y fields. The landing restrictions are `x ≥ 3`, `y ≥ 1`, `x + y < 7` and `2x + y ≤ 10`. The chart shades their intersection, and the check shows the substituted result for each rule. A point on a dashed line fails equality; a point on a solid line is allowed only if it still meets every other restriction. There are five valid points: `(3, 1)`, `(3, 2)`, `(3, 3)`, `(4, 1)` and `(4, 2)`.

Checking a valid point places the landing pad; changing either coordinate requires checking again. Launch the glider and watch it deliver the crate to the selected pad. **Show landing** skips the animation if desired. The local **Route Scout** badge persists across reloads. The field mission does not change expedition XP, equipment or teacher-assigned lessons.

For a classroom pilot, compare `(3, 4)` with `(4, 2)`: both lie on a boundary, but only the second is safe. Ask students to explain which inequality excludes the first point and to find a different valid landing. Keyboard and simulated touch checks do not replace a pilot on real phones.
